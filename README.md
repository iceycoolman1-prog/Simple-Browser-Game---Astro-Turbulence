# Project Title
Astro Turbulence
## Project Option
Simple Browser Game

## Project Description
A simple, ten level game where you control a floating probe. Your goal is to dodge a set amount of asteroids.

## Theme Interpretation
The game takes place in space, the player is a space probe and the obstacles are asteroids.

## Intended User or Player
The game is intended for players who enjoy the "Bullet hell" genre of games. It's a very short and simple game loop.

## User or Player Goal
The player should avoid ten levels worth of asteroids.

## Main Features
The main content is the game itself, there is an simple interactive start menu and game over screen. There is a score and level counter.

## JavaScript Features
Javascript controls the levels, player, and asteroids as well as all of the interactive features such as moving the player, restarting the level, and starting the game in general.

## Responsive Design
The game area AND the player/asteroids are scaled accordingly depending on the screen size.

## User Testing
I did not submit the game for prototype testing, instead I have some friends test it out and provide criticism. In the primitive state, we found that the game did not restart smoothly, they had trouble learning how to play without proper instructions, the hitbox would sometimes be in one place while the actual probe was in another, and overall there was visual muddiness and the look of the background was too similar to the game area. Initially, the game was meant to be based on Doctor Who, so another point of criticism was the lack of any iconography, however I chose to scrap this for the sake of time and lack of skills.

## Revisions
I added a restart button and made a simple level system.
I added a footer containing the simple objective and controls.
I used a tutorial to make a moving, environmentally-interactive player that would only activate the lose-state if the sphere itself touched an asteroid.
